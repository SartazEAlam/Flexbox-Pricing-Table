# Flexbox-Pricing-Table

# 💳 Responsive Pricing Table (Flexbox)

A clean and responsive **pricing table UI** built using **HTML and CSS Flexbox**.  
This project focuses on **responsive design**, proper **scroll behavior across devices**, and modern CSS styling.

---

## 🚀 Features

- 📱 Fully responsive (Desktop, Laptop, Tablet, Mobile)
- 🎯 Flexbox-based layout
- 📜 Scrollable content on all screen sizes
- 🖼️ Full-screen background image (no repetition)
- 🎨 Gradient-based pricing cards
- 🔤 Google Fonts integration
- 💡 Beginner-friendly code structure

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Flexbox**
- **Media Queries**
- **Google Fonts**
